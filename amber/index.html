开始使用

Amber 是面向 iPhone 和 iPad 的数据库客户端，要求 iOS/iPadOS 26 或更新版本。当前界面为简体中文，个人模式无需 Amber 账号。远程数据库需要你自己的服务器、网络访问条件及有效数据库凭据；Amber 不提供托管数据库或数据库账号。

常见问题

支持哪些数据库？

当前支持 MySQL、PostgreSQL、MongoDB 单节点、Redis 单机，以及通过“文件”选择的本地 SQLite 数据库。其他品牌的兼容性取决于其协议及服务器功能。0.1.0 (4) 起可使用 SSH 单跳/多跳隧道及 SOCKS5 认证代理。MongoDB SRV/副本集、Redis 集群/哨兵、HTTP CONNECT、Wi-Fi 自动代理、SFTP 获取及客户端 TLS 证书尚未接入。

为什么无法连接？

请确认主机、端口、账号与数据库名称，以及设备所在网络是否能访问服务器。局域网连接可能需要系统的本地网络权限。使用 TLS 时，服务器证书必须满足所选校验方式；完全校验是默认值；可明确关闭 TLS，包括 PROD，应用不会自动降级。SSH 或代理不能代替数据库 TLS。请勿为排查问题把数据库直接开放给整个互联网。

能执行任意 SQL 或写入吗？

SQL 编辑器仅执行经过检查的单条只读查询，并限制结果数量。数据变更和导入使用各自的审核与确认流程；能力随引擎、对象和账号权限而不同。结构对比可生成迁移脚本，当前不自动执行结构变更。请先使用专用测试数据库及最小权限账号验证操作，提交前核对 SQL 与影响范围。

密码和连接会同步到 iCloud 吗？

0.1.0 (2) 起，数据库密码允许通过系统 iCloud 钥匙串同步；请在系统设置中开启钥匙串。0.1.0 (6) 起，连接配置可经 Apple iCloud KVS 在同一 iCloud 账户的设备间同步；升级已有配置后，请到“我的 → iCloud 同步”确认账户并首次开启。连接名称、地址、用户名、数据库选项及 SSH/代理元数据会同步；密码、私钥、本机 SSH 指纹、SQLite 文件、查询库、结果与 AI API Key 不进入配置同步。账户切换时会暂停，冲突保留双方供选择，接收配置不会自动连接；新目标或恢复配置的凭据需明确重新确认。页面仅显示本机提交/接收，不能证明其他设备已收到。App 只能显示本机密码是否允许同步，不能确认其他设备是否已收到；迁移冲突或待迁移时会保留可用的本机密码并提示。0.1.0 (4) 起 SSH 密码和支持的私钥也允许系统钥匙串同步；代理密码仅在本机。详情见隐私政策。

如何导入 SSH 私钥？

0.1.0 (5) 起，可通过系统文件选择器或明确点击系统粘贴按钮导入私钥，支持 Ed25519、RSA、ECDSA P-256/P-384/P-521，以及 OpenSSH、PEM、PKCS#8 等对应封装。加密私钥需要输入解锁口令；口令不保存，只有导入成功才替换当前凭据。私钥默认遮蔽，归一化后的私钥保存在允许系统 iCloud 钥匙串同步的独立服务中；App 无法确认其他设备是否已经收到。SSH 证书、硬件密钥、PuTTY PPK 和 DSA 尚不支持；应用生成的新密钥仍为 Ed25519。原始私钥文件和剪贴板中的副本由你管理。

怎样使用导入和导出？

从表的工具入口选择文件并核对解析和列映射，导入写入前请检查审核信息。导出和分享会生成包含所选数据库数据的文件；这些数据文件不由 Amber 自动加密。请自行选择安全的存储位置和接收者。

怎样使用 AI 问数？

在“我的 → 设置 → AI 服务”中填写你自己的 HTTPS API 基础地址（通常包含 /v1）、模型名称和 API 密钥。当前支持兼容 OpenAI Chat Completions JSON 模式的服务。发送问题时，会向你指定的服务发送问题、数据库引擎及所选表名和表结构；不会自动附带数据库结果行或数据库登录凭据，但你输入的问题可能包含业务信息。0.1.0 (3) 起，追问会附带当前对话已完成的问答及生成 SQL；切换服务或数据库引擎会清空历史。SQL 解释与改写会发送当前 SQL，可能包含字面值，请先核对。改写需你明确应用到编辑器，查询结果图表在本机生成。服务费用、额度和数据保留由服务提供者决定。生成的 SQL 需要你点按运行，并经过只读检查；写入不会在问数中直接执行。

怎样使用 SSH 与 SOCKS5？

在连接的网络设置中配置 SSH 跳板/逐跳认证，或 SOCKS5 地址与认证。新版首次 SSH 连接自动记录指纹，之后自动核对，变化时阻断；首次连接前请自行确认服务器身份。每次数据库操作拥有并关闭自己的隧道，连接中断后下一次操作可重新连接，不自动重放未知结果的写入。SSH 与 SOCKS5 暂不能组合；请使用专用测试环境核对多跳、TLS 与取消行为。

运维 AI 和结果分享会发送什么？

主动请求运维 AI 时发送选中慢语句/会话的指标、采样限制与经字面值/注释处理的 SQL/计划摘要，标识符可能仍含业务信息；不自动发送原始计划、服务器错误或结果行。复制结果进入系统剪贴板，可设置到期；导出 CSV/JSON 不自动加密或脱敏。当前脱敏规则仅本机草稿/预览。

团队与网关可用吗？

当前仍是个人测试版，团队后端和团队网关尚未接入；个人连接配置同步从 0.1.0 (6) 起提供。

怎样反馈 TestFlight 问题？

可以通过 TestFlight 的“发送 Beta 反馈”或上述支持邮箱反馈。请注明构建号、复现步骤和数据库类型，并在发送前检查截图与日志是否包含凭据或数据库内容。TestFlight 安装、诊断和反馈由 Apple 提供，受 Apple 的相关政策及你的设置管理。

Support

Amber is a native database client for iPhone and iPad running iOS/iPadOS 26 or later. The app interface is Simplified Chinese. Personal mode does not require an Amber account. Bring your own reachable database and credentials. This early beta supports MySQL, PostgreSQL, single-node MongoDB, standalone Redis and local SQLite files. From build 0.1.0 (2), you can configure your own HTTPS OpenAI-compatible Chat Completions service and model. Questions, engine type and selected table names/schema are sent to that service; database result rows and database login credentials are not automatically included. From build 0.1.0 (3), follow-ups include completed questions, replies and generated SQL from the current conversation. SQL explanation and rewriting send the current SQL text, which may include literal values; rewrites require explicit application to the editor. Result charts are created on-device. Your typed question, history and SQL may contain sensitive data. Provider charges and retention follow its policies. Database passwords can use system iCloud Keychain, subject to your system settings; From 0.1.0 (6), connection profiles may sync through Apple iCloud KVS within the same iCloud account. After upgrading existing profiles, confirm your account and enable connection sync in My → iCloud Sync. Profile names, hosts, usernames, database options and SSH/proxy metadata may sync; passwords, private keys, local SSH fingerprints, SQLite files, query history, results and AI API keys are excluded from profile sync. Account changes pause sync; conflicts retain both versions. Received profiles do not connect automatically, and new targets or restored profiles require explicit credential confirmation. Local submit/receive status cannot prove delivery to another device. Build 0.1.0 (4) adds single/multi-hop SSH and authenticated SOCKS5 routing; from 0.1.0 (7), first-use SSH fingerprints are stored automatically and later changes block access, so verify target identity before first use; SSH credentials may use system iCloud Keychain while proxy passwords stay device-only. Explicit operations-AI diagnosis sends selected metrics, limitations and redacted SQL/plan summaries, with no automatic result rows or raw remote errors. Copy/export actions are explicit; clipboard expiration does not erase pasted copies. Team collaboration, gateways, HTTP CONNECT, automatic Wi-Fi proxy selection and SFTP are not connected.

Contact reallayoute@gmail.com with your OS version, app version/build, database engine/version, reproduction steps and redacted errors. Never send credentials, connection strings, server addresses or production data. Test changes on a dedicated test database and review every operation. Exported database files are not automatically encrypted by Amber.

From 0.1.0 (5), import Ed25519, RSA or ECDSA P-256/P-384/P-521 private keys from a selected file or an explicit system paste action. Supported containers include OpenSSH, PEM and PKCS#8. Encrypted keys require a local unlock passphrase that is not saved. Credentials change only after successful import. SSH certificates, hardware keys, PuTTY PPK and DSA are not supported. Newly generated keys remain Ed25519.

新版查询库、设置同步和 CA 文件导入

0.1.0 (7) 增加收藏、查询历史和外观/编辑器/通知偏好的独立 iCloud 开关，首次默认关闭。收藏和历史的 SQL、标题及连接名称使用私有 CloudKit 加密字段；UUID、时间、耗时、行数和失败状态作为普通字段保存。历史可能包含业务查询条件，请开启前核对。设置使用 Apple iCloud KVS 的白名单快照，锁定/隐私设置仍按设备保留。首次未确认云端设置时等待；使用本机设置需要明确确认。关闭不自动清除已有云数据，重新开启会按本机修改和已知删除意图对账。账户切换会关闭这些新增同步开关，页面状态不证明另一台设备已收到。

支持从所选 PEM/DER 文件导入受支持的 CA 信任根，保留主机名与 TLS 校验；CA 公共证书 DER 可随 V2 连接配置同步，不包含私钥或原文件路径。两端均需升级；完整原生文件导入、CA V2、收藏/历史/设置的真实双设备送达仍待验收。CA 链接导入和多跳扩展暂缓。iPad 编辑器按字号偏好显示实际查询上限，支持系统 SQLite 文件接收、显式检查保存与书签重开。本机通知使用通用内容；后台只有短暂预算，挂起或退出后不持续采样。

New query-library and preference sync

0.1.0 (7) adds separate, initially disabled switches for saved queries, history and whitelisted appearance/editor/notification preferences. SQL, titles and connection names use encrypted fields in the private CloudKit database. UUIDs, dates, duration, row counts and failure flags are ordinary fields. Review sensitive query conditions before enabling history. Preferences use Apple iCloud KVS; lock/privacy settings stay per device. Initial preference upload requires explicit confirmation when existing cloud content is not established. Disabling does not automatically erase cloud content; re-enabling reconciles local edits and known deletion intent. Account changes disable these new switches; local status is not delivery proof. Supported PEM/DER CA file import preserves TLS/hostname checks; public CA DER may travel in V2 profile sync, without private keys or source paths. Full native CA import and real new two-device sync remain unverified; CA URL import and multi-hop extensions are deferred. Local notifications contain generic text; background work has a short budget and does not continue while suspended or terminated.
